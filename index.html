01
Computer Vision + RAG · Full Stack
Multimodal AI for Construction Engineering
▾
The Challenge
Engineers needed to query complex CAD drawings in natural language — locating pipes, symbols, and title blocks across noisy, high-density sheets. No existing tool handled multimodal CAD understanding.
My Approach
Fused Gemini multimodal OCR with custom YOLOv10, v11, RF-DETR models for pipe segmentation, symbol localization, title-block detection. Hybrid inference layer merging OCR + CV into structured JSON.
The RAG Stack
Semantic chunking preserving sheet boundaries → Azure OpenAI embeddings → hybrid vector + keyword retrieval → GPT-4 grounded answers with sheet-level citations and confidence-based human-review routing.
Deployment
React + Next.js → Azure App Service. CV on Azure ML GPU Endpoints. CI/CD via GitHub Actions with shadow releases, rollback orchestration, and a self-healing agent for dependency updates.

02
Autonomous Driving · Edge AI
Real-Time Perception & Fleet Diagnostics
▾
The Challenge
Autonomous vehicles needed real-time detection on NVIDIA Jetson under strict latency. Engineers spent ~2 hours diagnosing failures from 50+ TB of unstructured AV data (LiDAR, CAN bus, logs, manuals).
Perception Stack
Fine-tuned YOLOv10 with mosaic + copy-paste augmentation → 95% mAP. Converted to TensorRT for 3× latency reduction on Jetson. Trained across YOLOv5/v8/v10, ResNet for detection + recognition.
RAG Diagnostics
50+ TB ingested → semantic chunking → Titan G1 embeddings (AWS Bedrock) → hybrid k-NN on OpenSearch. LlamaIndex query engine with graph-based routing improved MRR by 35%. Powered by Llama 2.
MLOps & Impact
SageMaker Pipelines + Step Functions cut retraining cycle by 60%. Deployed on AWS EKS with shadow deployments. 99.9% uptime. Diagnosis time: 2 hours → 10 minutes.
